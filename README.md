
# CloudStore

**Distributed E-commerce Platform**

A distributed e-commerce application built using
ASP.NET Core microservices.

## Technologies

- C# / ASP.NET Core
- PostgreSQL
- RabbitMQ
- Redis
- Envoy Proxy
- Docker
- OpenTelemetry
- Prometheus
- Grafana

## Architecture

The application consists of independent microservices,
each responsible for a specific business domain.

## Infrastructure

The application is planned to run on a self-hosted
Linux virtual machine using VirtualBox and Docker.
